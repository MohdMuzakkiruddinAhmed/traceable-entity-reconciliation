# Contributing

Install the development/fullstudy dependencies, run pytest, and verify saved results before proposing changes. Add meaningful controls when changing identity, units, blocking, lineage or query semantics. Keep evaluator truth outside inference features. Use new run IDs for experiments; preserve previous results and configurations.

Document task construction, units, missingness, denominators and exploratory amendments. Include negative results. Do not attribute matching gains to graph storage when relational controls use identical evidence. Do not equate bounded candidate output with computational complexity or production-scale validation.

Keep credentials and original privacy-bearing source data outside Git. Preserve upstream attributions/licenses. Update the results documentation only from executed measurements. Manuscript changes require rebuilding and rendered-page review.
