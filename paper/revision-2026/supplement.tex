\section{Protocol and verification}
The four graph tasks retain their original test views and common candidate pools. Original saved probabilities and method-specific validation thresholds define attribute-only (A) and gated-context (C) maps. Both methods process pairs in descending score order with lexicographic endpoint tie breaking, same-type eligibility, and one accepted partner per endpoint. Canonical identifiers are hashes of the endpoint pair. Gold labels are used only for evaluation. The same source projection, eight queries, and oracle apply to both methods.

There are four datasets, three seeds, two methods, and eight queries: 192 fresh method/query executions, representing 96 paired comparisons. All SQL and graph answer sets are equal, all oracle workloads are nonempty, and contextual canonical links and 96 contextual query metrics reproduce the original records. The 24 method-specific identity maps satisfy one-to-one constraints. All inspected original inputs retain their SHA-256 values. The additional control manifest records 748 passed checks. The full project test suite was rerun separately: 36 passed, zero failures, errors, or skips.

Query F1 is $2|E\cap A|/(|E|+|A|)$ for oracle set $E$ and actual answer set $A$. Table values below are arithmetic means of seed-specific F1, unless explicitly labelled summed-trial totals. Seeds share original source populations; differences are descriptive. No new query bootstrap, pooled confidence interval, multiplicity adjustment, or confirmatory significance test is asserted.

\section{Independent WDC split audit}
The benchmark paper describes offer-disjoint train, validation, and test splits [1]. The retained pairwise archives used here show a discrepancy. The independent parser reads the publisher's \texttt{id\_left} and \texttt{id\_right} as string offer IDs, unions both endpoints in each split, and intersects these offer sets. It does not substitute cluster IDs, generated source UIDs, or pair IDs. Every intersecting ID has identical cluster, title, description, brand, price, and currency fields across the relevant files. Hashed example records are retained without reproducing offer text.

All 27 independently computed cells reproduce the original saved split audit. Eighteen have training/test and/or validation/test intersections; all nine 100\%-unseen cells have none. The diagnostic subset retains only test pairs with neither endpoint in training or validation. No official pair list, training data, threshold, or reported matching output was modified. The reason for the discrepancy with the intended split design remains unresolved; these findings concern the exact archived bytes below and do not characterize every benchmark release.

\section{Reproduction and material index}
Build the PDFs with \texttt{python build.py}; rebuilding the manuscripts does not execute experiments. The source ZIP supplies complete editable LaTeX, fixed figure sources, measured CSV/JSON outputs, and verification reports. In the complete KG-ERP project, use the pinned full-study environment and run the control script against an empty output directory:

\begin{quote}\small
\begin{verbatim}
python analysis/run_controls.py --project KG --output NEW
\end{verbatim}
\end{quote}

\noindent Replace \texttt{KG} with the complete project path and \texttt{NEW} with a new empty result directory. The command uses \path{results/all-datasets-v1}, the documented source views, and retained WDC archives. It writes only the new output directory; generic truth persistence is disabled. It loads BPI fitted estimators solely for frozen attribute-score replay, and never trains a model. Paths can point to a restored GitHub release using its documented materialization/acquisition workflow.

\begin{itemize}
\item \path{data/query_controls.csv}: 192 method/query rows with exact denominators and SQL/graph parity.
\item \path{data/query_paired_differences.csv} and \path{data/query_paired_means.csv}: 96 seed-paired differences and 32 query means.
\item \path{data/identity_controls.csv} and \path{data/identity_totals.csv}: 24 method/seed maps and eight summed-trial summaries.

\end{itemize}
