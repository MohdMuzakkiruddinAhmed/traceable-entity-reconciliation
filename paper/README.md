# Research manuscripts

The current five-dataset sources are in fullstudy/: detailed.tex, ieee.tex, references.bib, generated tables/data and vector/raster figures. output/pdf/ contains the detailed article, IEEE draft and supplement. The original four-page source/main.tex and its generated evidence are retained as a historical two-dataset draft.

Run scripts/build_fullstudy_paper.py from the project root after installing requirements.paper.lock and LaTeX/IEEEtran tools. This rebuilds from bundled generated artifacts without original datasets or model fitting. Numerical/visual verification records and portable rebuild evidence accompany the sources. Manuscripts retain dated provenance/disclosure information and anonymous draft status.
