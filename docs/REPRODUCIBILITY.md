# Reproduction levels

1. **Control tests.** `python -m pytest -q` runs all 36 tests without dataset downloads. The WWI packaging-unit test creates a small source fixture and exercises the actual adapter.
2. **Saved-score checks.** `python scripts/verify_saved_results.py` recomputes 312 graph matching rows and 810 WDC official/disjoint rows, accepted-link audits, and one-to-one controls. A source-only checkout passes 2,270 checks; restoring the companion models adds 39 model-hash checks, producing 2,309. This is not raw-input score replay.
3. **Paper and supplement.** `python paper/revision-2026/analysis/verify_manuscript.py` independently recomputes included revision summaries and checks the existing PDFs. Without local TeX logs, 1,434 checks run. `python paper/revision-2026/build.py` rebuilds both manuscripts; the verifier additionally checks those two logs when present. The historical fully built manuscript record has 1,436 checks.
4. **Models and permitted source materials.** Restore the companion ZIP with `scripts/fetch_research_materials.py`, then run `scripts/materialize_release_data.py`. Asset and decoded-file hashes are checked. Original DataCo matching names are not reconstructed from the privacy derivative, and WDC raw offer text requires official acquisition.
5. **Frozen-source query and split controls.** In a workspace with the original required views and archives, run `python paper/revision-2026/analysis/run_controls.py --project . --output results/new-paper-controls`. This reexecutes 192 method/query cells, verifies original contextual links, diagnoses BPI fallback thresholds, and independently parses all 27 WDC split cells. The recorded original execution passed 748 checks. It does not refit models or policies.
6. **Full source/model replay.** The original five-dataset verification includes 3,136 historical checks across frozen scores, queries, source integrity, and original hashes. It requires the complete original source workspace, including separately acquired inputs and the earlier manuscript artifacts retained in the repository. Sanitized input bytes cannot be treated as original raw input bytes.
7. **Retraining.** Fresh training requires a new run ID, source acquisition, the recorded configuration and dependencies, and the declared adapter semantics. The expansion has not undergone independent fresh-environment retraining. The earlier primary study has a separate retraining replication; it does not establish replication of the expansion.

Seeds reuse original populations, and WDC test pools repeat across development sizes. Mean differences are descriptive. Keep candidate-conditioned metrics, complete-positive-universe pair metrics, final accepted links, query sets, preconstraint stress rates, and scaling retrieval denominators separate.
